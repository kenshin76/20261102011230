# SIGNALAB — 계측기·전자부품 B2B 판매몰 프로토타입

장바구니 자동 견적(1초 견적서 PDF), 회원 유형별 가격, 견적→주문 전환, PG·무통장 결제, 전자세금계산서, 상담 챗봇, 관리자 백오피스를 브라우저 안에서 체험할 수 있는 **제안용 웹 프로토타입**입니다.

- 브랜드(SIGNALAB), 상품 브랜드(ORVEX · LUMIQ · KAIRO · PRAXIS-E), 회사·대학·사람·가격·주문은 모두 **시연용 가상 데이터**입니다.
- 결제(PG), 국세청 사업자 상태 조회, 전자세금계산서 발행, 이카운트 연동은 **브라우저 안에서 동작을 재현**한 것이며 외부 서비스와 통신하지 않습니다.
- 정식 구축·납품 또는 운영 중인 서비스가 아닙니다.

## 실행

HTML · CSS · JavaScript만 사용하는 정적 사이트입니다. 빌드 과정이 없습니다.

```bash
cd prototype
python3 -m http.server 8000
# http://localhost:8000/index.html
```

GitHub Pages에 그대로 올려도 동작합니다. 글꼴(Pretendard · JetBrains Mono · Space Grotesk)만 CDN에서 불러오고, 연결이 안 되면 시스템 글꼴로 표시됩니다.

## 기능 살펴보기 (시연 순서)

로그인 화면의 「체험 기능 안내」, 쇼핑몰 하단 또는 관리자 메뉴 하단에서 안내를 열 수 있습니다. 안내에서 기능을 선택하면 체험 계정을 전환한 뒤 해당 화면을 엽니다. 일반 쇼핑 화면에는 안내창이 자동으로 표시되지 않습니다.

1. 회원 유형별 가격 노출 — 비회원·승인대기는 「회원 전용 가격」
2. 대학 5% 할인 · 예외 상품 — 조합별 기준가 → 할인 → 10원 절사, 할인 제외·교육용 정찰가
3. 장바구니 → 1초 견적서 PDF — 견적번호 `Q-YYYYMMDD-NNNN` 자동 채번, 30일 유효, 발행 소요 시간 표시
4. 견적서 → 주문 → PG 결제 — 견적 금액 그대로 주문, 결제 시도별 ID, 서버 금액 검증, 중복 결제 차단
5. 담은 뒤 가격이 바뀌면 재확인 — 변경 내역을 보여 주고 확인한 뒤에만 발행
6. 유효기간 만료 견적 — 체험 시간을 31일 뒤로 옮겨 주문 전환 차단, 현재 가격으로 재발행
7. 가입 · 사업자 진위확인 · 승인 — 검증번호 확인 → 계속·휴업·폐업 조회 재현 → 관리자 승인
8. 입금확인 → 세금계산서 — 주문당 관리번호, 응답 지연 시 먼저 조회해 중복 발행 방지
9. 옵션 조합 가격 엑셀 업로드 — 전체 행 검사, 오류가 하나라도 있으면 전체 반영 보류
10. 상담 챗봇 — FAQ 버튼, 키워드 답변, 내 견적서 찾기, 상담원 연결 기록
11. 이카운트 ERP 연동 준비 — 품목·거래처 코드 매핑 현황, 판매 입력 데이터 미리보기 (실제 전송 없음)

## 화면 구성

**사용자 판매몰 (반응형)** — 로그인 · 회원가입(3단계) · 승인 대기 · 홈 · 카테고리 8종 · 검색 · 상품 상세(옵션 조합별 가격표) · 장바구니 · 견적서(PDF 미리보기·다운로드) · 주문서 · PG 결제창 · 주문 상세 · 마이페이지 · 내 견적함 · 주문 내역 · 상담 챗봇

**관리자 콘솔** — 대시보드 · 가입 승인(진위확인 결과·증빙·유형/등급 지정·반려) · 회원·등급 · 상품·조합 가격표(예외 규칙·품목코드·판매 여부·유형별 적용가 미리보기·변경 이력) · 엑셀 일괄 업로드 · 가격 정책 · 견적 관리(스냅샷 vs 현재가) · 주문·입금확인(상태·송장·전액 취소) · 전자세금계산서 · 챗봇 FAQ·문의 · 이카운트 연동 준비 · 기본 설정(공급자·직인·유효기간·입금 기한·카드 결제 증빙 규칙)

## 가격 계산 규칙

```
기준가(옵션 조합별) → 회원 유형 할인(일반 0% · 대학 5% · 대학원생 5%) + 등급 할인(우수 +2%)
→ 상품 예외(할인 제외 = 기준가 / 고정가 = 모든 회원 같은 가격) → 10원 단위 절사
```

- 비회원 · 승인 대기 · 반려 회원에게는 가격 대신 「회원 전용 가격」을 보여 줍니다.
- 견적서와 주문에는 발행 시점의 단가·수량·배송비·부가세·합계를 그대로 저장합니다. 이후 가격과 배송 정책이 바뀌어도 유효한 견적으로 전환한 주문 금액은 바뀌지 않습니다.
- 공급가 30만 원 이상 무료배송, 미만은 배송비 4,000원(공급가에 포함해 부가세 계산).

## 데이터 저장

입력 · 업로드 · 견적 · 주문 · 관리자 변경 내용과 로그인 상태는 이 브라우저의 `localStorage`(`signalab-demo:2026110201:v1`)에 저장되어 새로고침해도 유지됩니다. 로그인 화면이나 「기능 살펴보기」의 **체험 데이터 초기화**를 누르면 처음 상태로 돌아갑니다.

상담 기록은 회원별로 분리합니다. 계정이 바뀌면 주문서 임시 입력·PDF 캐시·상담창을 정리합니다. 화면·계정이 바뀌면 이전 확인창을 닫고, 진행 중인 결제 시연의 후속 작업을 중단합니다. 주문 취소 실행 직전에도 현재 계정과 주문 소유권을 재확인합니다. 기존 공용 상담 기록은 소유자를 확인할 수 없어 더 이상 표시하지 않습니다. 가입 시 입력한 비밀번호도 체험 데이터로 브라우저에 저장되므로 실제 사용하는 비밀번호를 입력하지 마세요. 실제 서비스의 인증·권한 검증은 서버에서 구현해야 합니다.

## 프로토타입 범위

- 견적서 PDF는 브라우저에서 A4 이미지를 그려 PDF로 묶습니다. 본 구축에서는 서버에서 텍스트 기반 PDF를 생성합니다.
- 회원가입의 증빙 파일은 PDF·JPG·PNG, 10MB 이하만 허용하고 이름만 기록합니다. 입력한 체험용 비밀번호로 다시 로그인할 수 있습니다.
- 사업자 조회는 등록된 체험 번호의 결과만 재현합니다. 임의의 번호를 실제 계속사업자로 판정하지 않습니다. 대표자·개업일자를 포함한 실제 진위확인 API 연동은 본 구축 대상입니다.
- 대시보드 추이는 저장된 견적·주문의 날짜로 집계합니다. 초기 견적·주문 이력은 가상 데이터입니다.
- AI(문서 기반) 상담, 이카운트 실제 전송은 제안서의 2단계 범위로, 화면에는 준비 상태만 표시합니다.
